## Findings considered and rejected

- **Autocomplete static asset as a Cloudflare quota problem**: rejected. It is
  lazy, compresses to roughly 78 KiB, and Workers Static Asset requests are free
  and unlimited. Mobile transfer/parse cost can be profiled later.
- **Change the anonymous schedule cookie from `SameSite=Lax` to `Strict` for
  CSRF**: rejected. Mutations are POST, and Lax already blocks cross-site POST
  cookie attachment; Strict would add navigation friction without a demonstrated
  integrity gain.
- **Treat `webSocketClose(...).close()` as a resource leak**: rejected. It matches
  current Cloudflare Hibernation WebSocket examples and is safe, though no longer
  required with the current compatibility behavior.
- **Replace dynamic server-module imports solely for cold-start performance**:
  rejected pending bundle and runtime measurements; the reported millisecond
  cost was unsupported.
- **Move exact-version dependencies or generated router casts as urgent cleanup**:
  rejected. `npm audit` found no vulnerabilities, generated casts are framework
  convention, and dependency classification alone does not change bundle output.
